# Phota 评分细则 v2

制定：2026-10-27。状态：规则已制定，**待实际评测前登记冻结**，无新评测成绩、脚本或标注结果。对应 [精进路线图](../superpowers/plans/2026-10-24-phota-training-roadmap.md)。禁止微调、蒸馏和权重训练。

## 1. 证据能支持什么

| 证据 | 可以评 | 不能据此声称 |
| --- | --- | --- |
| 原片＋原始模型输出＋最终指令 | 事实、方向、需求判断、可执行、预计专业适配、现场关联 | 动作已完成、成片真的改善、实际步骤 |
| 真实前后帧＋原样指令＋是否照做 | 当步执行与效果、新增问题 | 未执行的另一版会怎样 |
| 完整轨迹＋实际最终照片 | 成功率、步骤、放弃、真实成片分 | 缺失的步骤不存在 |
| 同输入建议盲评 | 建议偏好和预计适配 | 真实成片胜率或所有人的偏好 |
| 匹配条件真实成片盲评 | 实际专业分和成片偏好 | 不同光线/场景的差异只由版本造成 |

建议适配分与成片分分表。缺证据记“暂无数据/无法判断”，不补0或默认通过；模型自评分不代替人工评价。坐标是观测估计，不是视觉真值。

任何比率分母为0时记“不可得”，不能填0%或100%；报告每个指标的分子、分母、未知数及可评分覆盖率。缺失指标不满足完整晋级要求。

## 2. 单位、分组与冻结

记录案例、作者/人物/拍摄组、会话/拍法/步骤ID、模式、画幅、源图/输入哈希、模型和参数、提示/实现/规则版本、上下文、时间、原始观察/导演、最终指令及全部请求尝试。

会话是同一天连续同一拍摄任务，不为凑次数拆分；换子场景可标记。拍法是同一目标与条件的完整尝试，换法产生新ID，但旧尝试保留。

- 开发集可反复修改；回归集使用和暴露留痕，据其结果改方案后登记开发曝光。
- 封存按作者/人物/拍摄组关联隔离，同一身份、连拍、裁切、调色版本不能跨集合。已曝光9位作者不可重新封存。
- 同原片不同画幅分别评稳定性，不另增独立样本。
- 启动前登记规则SHA256、候选、输入、样本清单、次数、总量与停止条件；改版本须新开批次，不能挑最好输出。
- A/B顺序随机，身份映射留档。先看图片和明确意图标原片，再看建议，避免候选说什么就标什么问题。

## 3. 人工标注流程

1. 不看建议，标原片：**保留即可 / 有值得解决的问题 / 无法判断**。列主要问题、证据、作者明确意图；可选探索与必要修正区分。
2. 查事实、空间、方向与前提，再判建议针对什么问题。
3. 每项错误标确认/可疑待核验/未发现，留下图片或记录证据。启发式报警不直接定罪。
4. 静态建议评适配与创意；真实前后照片另评效果与成片。
5. 硬错和可疑项全部复核，另预先随机抽至少20%普通案例复核。有且只有一位评分者时说明单评，不声称独立复核。
6. 事实分歧核验原图/记录；审美分歧保留，不强凑一致。未解决的硬错疑点阻止晋级。

暗调不自动等于欠曝；严肃不等于必须微笑；留白/不对称不因偏离模板就判坏。意图未知不假装知道，也不以“可能有意”豁免可见事实错误。

## 4. 硬错误：一票否决

| 类别 | 确认条件与例子 |
| --- | --- |
| H1 事实错误 | 图片可证伪的明确断言：没有花却让拿花，花压头发却说挡眼；看不清先列不确定 |
| H2 空间矛盾 | 同对象同帧描述与有效框/画面明显冲突：脸和头框居中却称紧贴左边 |
| H3 方向或动作含义错误 | 已知条件下与目标相反，或动作无法唯一理解：左右说反、降低手机和下压镜头混淆；信息不足却保证方向 |
| H4 前提不成立/无法执行 | 证据明确反证动作前提：把够不到的桌上花当手中花；未见脚却断言双脚站姿并纠正。未知先列待核验 |
| H5 虚假完成 | 没有证据或记录反证却声称完成：花仍压头发却说已经避开；“先试一点，再复看”允许 |
| H6 指令矛盾/对象混乱 | 同条最终指导互斥或混淆执行者/前后帧/目标到无法照做：手机固定与移动同时要求 |

分别审查内部原始错误和最终用户可见/行为错误。控制器拦住且未使用、未展示的内部草稿不混记为最终错误；错误观察继续驱动动作或进入展示的理由，仍计最终错误。两套结果均报告，不拿拦截成功抵消最终错误。

**硬错误率＝含至少一项确认硬错误的可评分有效输出数／全部可评分有效输出数。** 一条多错分子只计一次，另列类型与错误事件数。有效输出中的未决事实单列，不当无错；晋级须无最终展示或驱动行为的确认及未决硬错，且披露可评分覆盖率。完全拦截、未使用且未展示的内部错误另报，不单独触发最终硬错否决。

接口/空响应/格式失败没有可评输出，不能算零错误；另报所有尝试成功率与最终不可用率。一票否决指该冻结候选本批不能晋级，不是永久不能改进。有限样本零错只能写“本批未发现”。

“未决硬错”针对模型已经作出的、可能影响指导的明确断言。模型诚实表示看不清、不知道或请求补视野，本身不是硬错疑点；另评其是否合理、有无过度回避，防止把承认不确定也处罚为错误。

## 5. 空间描述约定

坐标统一当前输入图左上(0,0)、右下(1,1)。画面左右、模特身体左右、手机平移、镜头旋转、画面主体移动分别描述。

- 脸中心x<.40称偏左，.40≤x≤.60称横向居中，x>.60称偏右；边界±.03为人工复核带。
- “贴边”须相应主体框距该边≤.05；>.10与贴边冲突，.05–.10或框不可靠时待核验。脸中心不能代替头发框。
- `headTop`为可见头顶到上边界归一化距离；>.25可客观称留空较多，.20–.25待核验。头已截断/缺框不能虚构数值。
- **这些是描述一致性阈值，不是摄影好坏阈值。** 居中、大留白、不等空间不能单独触发调整；仍需意图兼容的问题证据。
- 眼神方向模糊、深度未知或框矛盾时不保证改善方向；未来效果写试探与复看。

文字与错误坐标一致仍可能是观测错误。先对图核验，不因程序生成文字就当事实准确。以后调阈值须在开发集升版，不能针对封存失败临时移动边界。

## 6. 是否值得调整

先冻结原片标签，再将最终指令标为必要修正/可选探索/多余或有害/无法判断。首次稳妥指导和明确“换个拍法”分表，合理探索不自动算多余，“创意”也不免除事实与执行责任。

| 指标 | 分子／分母 |
| --- | --- |
| 不必要调整率 | “保留即可”原片却收到多余/有害首次调整的案例／该标签且有有效首次输出的案例 |
| 漏调率 | “有问题”原片直接拍或只给无关动作，未处理也未合理说明推迟主问题的案例／该标签且有有效首次输出的案例 |
| 无证据调整率 | 缺可追溯画面/测量依据却要求调整的条数／有效调整条数 |

漏调不只统计ready：花压头发却只让笑也算。先处理更重要问题、说明后续不是漏调次要问题；完整轨迹再核验是否解决主要问题。未知、探索和无有效输出单列，不悄悄挪分母。没有“保留即可”或“有问题”样本，相应率写样本不足。

## 7. 实拍、效果和步骤

默认记录Phota最终原话。用户自创/改写另标来源。前后尽量保持人物、光线、镜头、画幅与目标，只执行当前指导；换光、换焦段、额外指导、后期等记混杂，不能把差异都归因于该步。

执行标照做/部分照做/未照做/无法判断；效果标更好/一样/更差/无法判断，并记目标和新增问题。按错误指令照做也可以是执行完成，不能混淆执行与有效。

- 有效前后对：同指令、前后图齐、执行可核验、无明显归因混杂；重复导出只计一次。
- **单步有效率＝更好的有效已执行对数／全部已照做且效果可判的有效对数。** 分母包含一样、更差，三类比例都报。
- 另报执行覆盖率（可评分已照做对数/全部已发调整条数）、部分/未执行/缺图/混杂比例及原因，防止删掉难执行动作。未执行不当效果失败，但可能是不易理解/不可执行。
- 主验收步骤按独立执行动作计：一个执行者对一个对象作一项可独立核验的变化为一步。一条含k个独立动作计k步，交互条数另报。“降低手机并左移”计2步；“降低手机，保持朝向，再复看”计1步，保持约束与检查不另算动作。重复、改说法再要求动作也计新步；内部观察/修复不算用户步，但计请求/耗时/费用。
- “可以拍”计一条交互、零调整，原片直拍可为0步，不把内部两次调用计作两步。
- 用户保留率：用户愿保留最终图的拍法数/已开始有效拍法数。严格出片成功率还须有实际最终图、无确认硬错/未决硬错/遗留主问题，且适用成片维度均≥3。
- 同拍法上限4个独立调整动作，合并指令不能越过剩余动作额度。分母保留所有已开始有效拍法，放弃/4步未成功记未成功；缺结尾、技术不可用单列数量且不从总数消失。对不可判断的成功状态另报“未知”，不擅自断言失败或成功。
- 成功拍法步数须与严格成功率、未知/放弃数、交互数和动作数一起报，不能靠抛弃难例刷≤2步。

严格成功率主值为已确认成功数S/全部已开始有效拍法数N，属于已确认成功的保守比例。另报确认未成功F、未知U，满足S+F+U=N，以及可判定部分S/(S+F)；分母为0写暂无数据。未知不被重标为失败，比较版本时须并列U/N，不能靠增加未知改善已判定成功率。

拿A执行后的照片让B离线再看，不证明B建议有效。版本成片比较须匹配初始条件并平衡尝试顺序；无法匹配就各自描述，不作版本因果胜负。

## 8. 四维专业分，1–5分

先标“建议适配”或“实际成片”，同维度分表。前者评预计可行与合理，后者只看照片及明确意图。3分表示成立可用，不等于必须继续改；5分不保证人人喜欢。

| 分 | 光线 | 姿态神态 | 构图 | 环境利用 |
| --- | --- | --- | --- | --- |
| 1 | 关键细节明显丢失且违背目标，建议仍无视 | 不可能/明显别扭动作，或姿态严重破坏表达 | 无意切关键主体、强干扰仍未处理 | 虚构元素，或环境明显压倒主体、违背意图 |
| 2 | 看见问题但措施错配，如一味提亮明确暗调 | 泛泛放松微笑与意图不符，或紧张感干扰 | 调整片面，主要留白/干扰问题仍在 | 空喊借背景，关系牵强 |
| 3 | 光线与目标兼容，如阴天柔光自然、暗调保留细节 | 自然可执行，神态兼容；保持好姿态也可达标 | 主体完整、重心和留白成立，居中也成立 | 真实环境合理保留，简洁背景服务主体 |
| 4 | 现场窗光/侧光形成有目的层次，兼顾细节 | 手、重心、肩颈、视线协调，不僵硬 | 前后景/线条/位置有明确表达及收益 | 真实前景或道具与人物自然配合，不压主要表达 |
| 5 | 光线组织与情绪高度统一，或现有强光影已完整成立 | 姿态与瞬间神态共同表达，互动自然有辨识度 | 构图与情绪环境统一，复杂有秩序或极简很完整 | 环境自然参与叙事，有辨识度而非硬凑互动 |

这是锚点，不要求每张都侧光、互动或复杂构图；简单原片也能高分。任何硬错另行否决，不被专业分抵消。无人物姿态记N/A，与单人任务分开；看不清记无法判断，不能用N/A排掉抬分。

单图均分取预先适用且可判维度，同时报各维和缺失。+0.5目标只用匹配任务/条件的**真实成片**配对分差；不能用新版建议分减旧版成片分。先按作者/拍摄组求配对均差，再对组等权汇总，任一维平均不下降。缺失配对另列，不更改适用维度凑分。

## 9. 创意与现场关联

创意只评明确探索或实质新方案，保持好原片不因缺新动作扣分。

| 分 | 锚点 |
| --- | --- |
| 1 | 模板、换词，无实质差别，如每次微笑放松 |
| 2 | 有变化但现场关联弱，如任何地点都能侧头 |
| 3 | 真实元素形成可执行拍法，如借现有窗光转肩保留眼神 |
| 4 | 光、机位、动作或前景关系有适合现场的明确不同方案 |
| 5 | 有辨识度、与现场和人物意图统一，仍可执行和核验 |

新奇不抵消虚构或不可执行。改标题、同动作换说法、增加无关指令不算新拍法。

现场关联率＝关键现场依据经图片确认且实际用于拍法的有效输出数/提出实质拍法的有效输出数。“背景好看”不算具体关系；真实简单背景或光线可算。保持原片单列不强扣分。所有引用真假另列，不能靠一项真实引用遮住其他虚构。

## 10. 盲评与统计口径

同原片、请求、意图和画幅比较冻结新版/v16，六选一：**A更好 / B更好 / 差不多 / 都不好 / 原片最好 / 无法判断**。原片最好表示保持优于两条建议；即使某版恰好ready，也保留原始选择，仅标一致性，不能自动转成该版赢。

观测决胜率W/(W+L)，W新版获选、L v16获选。按全部有效评阅数另报平局、都不好、原片最好；无法判断/未评按发放总数报。公布所有原始计数和分母，不因不进W+L就省略非决胜选择。

晋级主分析限定公开新作者组：同一作者或关联人物/拍摄组算一单位，每组只预选一张、一个画幅、一个请求，选择在看输出前登记。其余相关案例作回归，不另加n；查出同身份合并重算。实拍按会话/人物聚类报告，重复人物或用户同场景不冒充独立作者。单用户偏好只支持该用户，不能泛化大众。

完整晋级要求同冻结候选至少30个**有决胜选择的独立作者单位**、p≥.60、95% Wilson下限>.50。总评阅量应更大以容纳非决胜。z=1.96，n=W+L，p=W/n：

`下限=(p+z²/(2n)-z*sqrt(p*(1-p)/n+z²/(4n²)))/(1+z²/n)`

30只是最低项目门槛；18/30=60%仍不能让下限超过50%。通过也仅支持“本批观测≥60%，有优于50%的初步证据”，不证明真实胜率至少60%或代表所有摄影者。

每批3–6组只为减少负担。同一冻结版本按预登记固定样本总量结束判定，不边看显著性边补到通过。改候选重新累计，旧反馈只作历史。决胜不足或缺代表性写证据不足，不排困难作者凑胜率。

A/B“都不好”和“原片最好”为共享选项，不能伪造新版/v16各自比例。对应质量门另用同输入单版本标注：不适用建议率（不适用输出/可判有效输出）、违背保留意图率（见不必要调整率）。两者新版不高于v16；记录匹配案例及不确定性，同时保留A/B两项原始分布。

不适用建议指至少满足一项：最终硬错、现场前提不成立、明确多余/有害、遗漏主要问题且未说明合理处理顺序。一条多项只计一次。单纯不合评分者口味但可行合理的风格探索不算不适用。未知单列；没有可判输出时该率不可得，不能默认通过。

## 11. 延迟、费用与失败

用户等待：提交本步当前帧到完整可执行文字可见，含观察/导演/修复/重试/网络；语音开始另计。后台预计算报耗时、命中、失效率与费用，不当免费。

平均指导费用＝本批所有请求估算费用/最终有效指导数，含失败、修复、候选、评审及后台废弃。无有效指导写不可用，不除零；失败不返回用量记费用未知，不填0。总费用、每条均值/中位数/P90、token和计价版本都报，估算与账单区分。

报告所有计划尝试、成功输出、最终不可用、超时及阈值。效率主单位是一次提交当前帧的逻辑指导请求，内部重试不增加分母；全部计划的逻辑请求在执行清单中保留。最终可用率＝有完整可执行输出的逻辑请求数/已提交逻辑请求总数；因故未提交的计划请求另报，不静默删清单。

效率门槛同时要求最终可用率≥95%和全批等待中位数≤5秒。全批排序中，最终超时/不可用请求的等待记∞；有限成功等待按实际全流程记录，用最近秩分位数（序号ceil(q*N)，q=.5或.9）计算。成功样本延迟只作条件分布，不能独自满足5秒门槛。超时阈值与允许重试在运行前冻结；失败不因延迟记∞而失去实际耗时记录。费用有未知部分时不能证明费用门槛已过。重试均计账，目标不是历史均价保证。

## 12. 记录表与晋级顺序

| 字段 | 必填内容 |
| --- | --- |
| 身份版本 | 案例/组/会话/拍法/步ID、模式、画幅、版本映射 |
| 原片意图 | 三类标签、主要证据；明确意图与推测分开 |
| 原样指令 | 执行者、动作、依据、复看目标 |
| 事实 | H1–H6、原始/最终、确认/可疑/无、证据 |
| 需求 | 必要/探索/多余有害/未知，是否漏掉主问题 |
| 执行效果 | 是否照做、图是否匹配、四类效果、原因和新问题 |
| 专业创意 | 建议/成片分表、四维、创意、关联依据、缺失 |
| 盲评 | 六选一原始选择及备注，映射不得重写 |
| 用量 | 全部请求、延迟、失败/修复/后台、费用未知项 |

判定顺序：数据有效 → 硬错/疑点 → 需求与执行 → 实拍效果/步骤 → 专业创意 → 盲评不确定性 → 效率。必需项缺数据不作完整晋级。高分不抵消硬错，少步不抵消低成功率，静态偏好不替代成片效果。

冻结后若规则本身有错，保留旧规则/结果并说明，升版重新登记，不悄改阈值或用户选择。
