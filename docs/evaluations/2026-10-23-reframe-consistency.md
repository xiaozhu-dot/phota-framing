# 出片指导：留白方向与连续步骤修复

当前代码版本 portrait-v16。只修改提示、动作协议和推理校验；没有微调、蒸馏、权重训练或 APK 打包。用户原来的 v11 盲选页面、映射与导出反馈保留。

## 已落实的改动

将“给视线前留白”和“减少头顶留空”变成独立的 camera_reframe 动作。当前图像的观察阶段提供脸部中心、头发顶部和画面视线方向，程序计算目标与转动方向；导演不能用相反目标坐标覆盖它。已有视线空间不反向挪回中心，未知位置不猜方向。

手机原地转向、手机升降、摄影师横走分别处理。未完成的留白目标不能通过改计划焦点绕过；当前画面确认达标后，允许同一拍法进入模特神态或互动步骤，避免旧留白目标被新的视线动作卡住。v16 还拒绝实际调整留白、却将计划标成 pose 的矛盾输出；缺省焦点可由合法动作目标补齐。

这些校验保证动作的一致性，不能证明“这张照片应当调整留白”。是否值得调整依然是需要改进的判断能力。

暗调男性原片已有较多左侧空间，v14 没有强迫反向重排。花丛坐姿继续允许直接拍摄，符合用户此前选择；不因作者是新手而强行改变姿势。

## 新作者检查及失败

新增 u/kolombod 的[首次人像原帖](https://www.reddit.com/r/photocritique/comments/1rc00ms/first_time_doing_portraits/)。作者自述人像知识和经验不足，并明确希望保留旋转散景与户外人工灯光。先核验原帖、查看原图并冻结审查问题，再调用模型；作者意图公平提供给两种版本，评论与审查答案不提供。首次使用属于新作者检查，此后该照片只能用于回归。

候选没有处理好“环境亮点”与“多余留白”的区别，虽然标题承诺保留散景，实际仍执行减头顶留空。因此不能将正常返回、正确转向或提到作者意图视为质量通过。该次离线候选耗时约 142 秒。后续核对发现离线评测发送原始照片，App 发送最长边 1024 的取景帧；这不能作为实机延迟统计，需对齐输入后另测。

另查看过咖啡馆人物照片，但作者只确认首次人像编辑，不能据此证明是拍摄新手；没有混入新手确认组，也没有发给模型评测。

## 验证与限制

- v16：82 项 Node 测试全部通过，涵盖 51 项出片协议/API 测试，以及方向、伙伴和语音回归。新的一致性用例先失败，再修复通过。
- Web 构建通过；独立代码复核未发现新的实质问题。
- v16 浏览器验证通过 27 个普通布局、54 个出片布局，以及真实界面中的新 reframe 指令展示、凭证路由、取消过期结果和拍摄状态。

目前共 6 位已核验的新手作者，样本很小；最初 5 张都经过用户反馈，新夜景也已曝光。没有总体准确率、审美胜率或实际成片改善证据。花束案例没有达到用户提出的捧花闻花、人物为主体的整体拍法；不能将它写成已完成。

摄影质量验收仍未通过。下一轮应优先补足有意留白的判断和可执行的道具互动，并使用尚未曝光的新手场景检查泛化，不能靠反复改同几张的答案制造进步。
