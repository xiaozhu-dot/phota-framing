# 出片前后景分离方向校验

沿用用户已批准的单步指导、独立观察和程序计算方向设计，修复 v20 将右前景压头建议为向右横移的缺陷。不微调、蒸馏或打包。

当前几何依据：固定朝向的小幅相机平移下，投影坐标为 (X-C)/Z，两层的相对变化为 C(1/Z_head-1/Z_obstacle)。前景与背景的符号相反。参考 OpenCV 官方针孔投影模型：https://docs.opencv.org/3.4.18/d9/d0c/group__calib3d.html 。只推算试探方向，不从单张图猜三维距离或保证成片。

- [x] 用独立三维投影测试覆盖前后景、左右及上下镜像、未知深度、无重叠、无效框。
- [x] 新纯模块计算一个干扰物包围框移离头部框所需的屏幕方向，再根据前后关系换算相机平移/升降；无效或未知输入拒绝计算。
- [x] 增加 camera_clearance 类型，方向来自冻结观察；明确目标关联，未完成不得换成抬花或放松表情；达标后允许进入下一步。
- [x] 独立实验提示增加 headBounds 与 overlaps.bounds，保留正式 v16 提示；用用户已曝光照片做回归，不叫独立测试。
- [x] 检查真实输出与原图、运行相关测试及 Web 构建，独立复核。101 项测试、81 个布局及 Web 构建通过；摄影质量未整体晋级，未宣称实际避开遮挡。详见 `docs/evaluations/2026-10-24-parallax-clearance.md`。

局限：包围框只是局部干扰物的近似，模型仍可能认错框或深度；屏幕最小挪移不是最短物理移动；多个干扰物、人物动作和旋转会影响结果。只给一个小幅试探，下一帧复看。
