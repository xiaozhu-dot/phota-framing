# Phota v2 计划（收集版真机反馈后）

日期：2026-11-10。说法见 [CONTEXT.md](../CONTEXT.md)。全部做完后只打一次 APK。

## 已定的决定

1. **标注**（只在收集版）：
   - 回合第一次指导时存一张指导前画面（尺寸和成片缩略图相同）。
   - 前后盲选：指导前画面与最满意的一张并排，左右顺序随机，不标明哪张是哪张。
   - 步骤标记：每一步标「有用 / 没用 / 做不到 / 没听懂」，状态为 ready 的步骤不标。
   - 共同题：整体帮助、步骤数、等待时间、场景对不对；另加各场景的专属题。
   - 速度和步数自动记录。
   - 回合在后台攒着，标注标签显示数字；离开拍摄页或停拍 5 分钟才提醒。
   - 清理：跳过就删；提交时附图则压成 512px 小图，原图删掉；7 天未标的回合变成未标注回合并删图。
2. **一个拍摄页**：
   - 去掉普通 / 出片两种模式。
   - 用 MediaPipe（Apache-2.0）的物体检测在手机本地分出四类场景：人像、人文街拍、动物、风景 / 其他。
   - 人像沿用现在的出片指导；街拍和动物用新提示词，不指挥路人和动物；风景沿用构图指导。
   - 新提示词用照片测试要花 API 费用，跑之前先报调用次数和大概花费。
   - 加第三方许可文件。
3. **前置摄像头**：自拍走人像指导，话直接对被拍的人说，默认开语音；保存的照片和预览一样是镜像的。
4. **页面排布**：
   - 顶部是拍摄 / 相册（照片分析和摄影集合并），收集版多一个标注。
   - 取景框尽量大。PRO 参数和语音收进「更多」。
   - 点宠物要一次指导；长按宠物开关自动指导，关掉时宠物睡觉。
   - 宠物一直面朝用户睡（试机后去掉了翻身背对）。睡着时点一下，宠物半睁眼指导后继续睡。
   - 新手引导：宠物走到各按钮旁用气泡介绍，可以跳过，不讲 AI 密钥。
5. **摄影集**：
   - AI 先看照片，决定问哪些关键信息并预填猜测；地名、人名这类看不出来、文案又需要的，要专门问。
   - 生成 3 条配文，带 3～5 个话题标签，可一键复制。语言由用户选，默认中文。
6. **宠物动画**：
   - Q19 清单全部做。
   - 道具两只宠物共用，和宠物一样的扁平画法（无描边），够大，托在身前或举到眼前，钳子 / 蹄子真的夹住；宠物本体在所有动画里不变形、不换样子。不用手势类道具（大拇指、比耶），试机时显得突兀。
   - 同一个玩笑每天最多一次；系统设置「减少动态效果」时只变表情；只在开着语音时说话。

## 顺序

1. 标注改造 → 2. 合并拍摄页 + 场景识别 + 新提示词 → 3. 前置摄像头 → 4. 页面排布 + 宠物睡觉 + 新手引导 → 5. 摄影集关键信息和配文；宠物动画分散在各步里做。

每步单独提交、跑测试。
